# Site — Santuário Santa Terezinha

Projeto inicial de site institucional e informativo, desenvolvido com HTML, CSS e JavaScript.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta `santuario-santa-terezinha` no Visual Studio Code.
3. Abra `index.html` no navegador. Se tiver a extensão Live Server, clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Páginas
- `index.html`: página inicial
- `igreja.html`: apresentação institucional
- `doacoes.html`: orientações sobre doações
- `bazar.html`: informações sobre o bazar
- `eventos.html`: divulgação de eventos e campanhas
- `contato.html`: telefone, WhatsApp, endereço e mapa

## Pastas
- `css/style.css`: estilos e responsividade
- `js/script.js`: menu móvel e elementos comuns do site
- `imagens/mascote/`: ilustrações da mascote Teófila

## Antes de publicar
Confirme com a secretaria:
- horários atuais de missas e atendimento;
- dias e horários de recebimento de roupas;
- quais itens são aceitos e em quais condições;
- datas do bazar e dos eventos;
- finalidade dos valores arrecadados;
- autorização para usar fotos, logotipo e nome institucional.

As informações não confirmadas foram redigidas com ressalvas para não apresentar dados incertos como oficiais. A imagem da Teófila é uma ilustração gerada para o projeto; a imagem não representa uma fotografia real do Santuário.
